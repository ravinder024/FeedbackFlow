# MVP Scope: Capabilities & Limitations

## Must Have (MVP Launch Blockers)
- Google OAuth authentication
- Role-based access (Admin, Moderator, Test Member)
- Test group creation with domain validation
- Widget script embedding on target domain
- Pin creation with DOM selectors + coordinates
- Observer mode with consolidated pin view
- Basic consent banner
- Auto-mask password fields

## Should Have (Post-MVP Phase 1)
- Threaded comments on pins
- Real-time WebSocket updates
- Pin filtering by status/user
- Email notifications
- Heatmap visualization
- Export feedback to CSV

## Could Have (Future Phases)
- Browser extension for better DOM access
- Jira/Asana integration
- AI-powered feedback insights
- Advanced analytics dashboard
- Mobile app support
- On-premise deployment option

## Won't Have (Out of Scope)
- Screenshot capture (intentionally excluded)
- Video recording
- Multi-language support in MVP
- Custom branding for widget

## Success Metrics for MVP Launch
- **Adoption**: At least 3 pilot teams actively using the platform within the first month.
- **Engagement**: Average of 10+ pins created per test group during pilot phase.
- **Reliability**: 99.9% uptime for the widget and dashboard during the first 90 days.
- **Feedback**: Positive feedback from at least 80% of pilot users in post-launch surveys.
- **Integration**: Successful embedding of the widget on at least 5 unique domains.
- **Security**: No critical vulnerabilities reported during the first 90 days.
- **Performance**: Widget load time under 500ms on target domains.
- **Compliance**: Full adherence to GDPR/CCPA for data handling and consent.
- **Scalability**: Support for up to 100 concurrent test groups without performance degradation.
- **Auditability**: Comprehensive event logging for all user actions.
- **Ease of Use**: Average onboarding time under 30 minutes for new teams.
- **Support**: Resolution of 90% of support tickets within 24 hours during the pilot phase.
